公开语料来自 [Name That LLM Open Pool](https://www.kaggle.com/datasets/crtproduction/name-that-llm-open-pool)。筛选保留记录为 CC BY、CC BY-SA 或 CC0 的样本，剔除池内标记的 Benchmarks Proxy、路由风险、官方题目重生成和疑似近邻，并与官方训练文本做规范化去重。6,282 条来自 349 个覆盖 18 类的题目组。20,286 条来自 1,920 个题目组，每类 1,127 条。

分组校正只用候选文本的词和词组相似度推测题目分组，再对同组重复的来源模型施加软惩罚。四次不同类别保留比例的模拟中，OOF 分数分别提升 1.91、0.82、1.86 和 1.32 个百分点。


## Kaggle 复现

已确认的最高公开榜分数为 44.9%。早期线上基线因 tokenizer 的结束符和填充符与训练配置相反而降至 5.8%。统一两枚特殊 token 后，官方可见示例在 Kaggle 与集群端的预测逐条一致。更高的分组验证结果需要继续用 Kaggle 隐藏集验证。
