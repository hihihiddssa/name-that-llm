# Name That LLM

用于 Kaggle [Name That LLM](https://www.kaggle.com/competitions/name-that-llm) 的文本来源识别项目。项目将段落归类到 18 个候选模型，结合 Qwen3 LoRA、字符与写作风格特征，以及按题目分组的交叉验证。

## 协作

收到仓库写入邀请后，可以从 `main` 创建自己的分支，推送改动并提交 Pull Request。也可以 fork 这个公开仓库，从 fork 提交 Pull Request。

Kaggle 的参赛队伍在竞赛页面单独管理。竞赛数据请从 Kaggle 获取，训练数据、模型权重、账号凭据和集群配置分别保存在各自的本地或私有环境。
